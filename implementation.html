Build order

  1. Publish this static knowledge base to GitHub Pages.
  2. Build/finish the public subscription website separately.
  3. Create the SEO pages and link them internally.
  4. Install analytics and advertising measurement.
  5. Connect WhatsApp to your customer/order system using an approved integration.
  6. Store order source/medium/campaign/content and referral information.
  7. Build the admin dashboard around revenue, CAC, renewal and LTV.
  8. Start Zambia advertising tests.
  9. Only scale after measuring completed payments.

GitHub Pages

  1. Create a GitHub repository.
  2. Upload all files in this folder to the repository root.
  3. Commit/push the files.
  4. Open repository Settings → Pages.
  5. Choose GitHub Actions or deploy from the main branch/root depending on your preferred GitHub Pages setup.
  6. Open the generated Pages URL and bookmark it.

Recommended next development step

Keep this repository as the marketing playbook. Keep the live customer-facing subscription application in its own repository or folder. That separation makes it easier to update strategy/content without risking the production application.
