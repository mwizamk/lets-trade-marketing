# Let's Trade ZM — Marketing Strategy Hub

A static GitHub Pages knowledge base containing the consolidated Zambia + global marketing plan.

## Included

- 90-day marketing strategy
- Zambia SEO page map and keywords
- 30-day social content calendar
- Meta / Google / TikTok advertising strategy
- WhatsApp sales and renewal funnel
- Analytics, UTM and conversion tracking
- KPI framework
- GitHub Pages implementation guide

## Files

- `index.html` — dashboard/home
- `strategy.html` — 90-day plan
- `seo.html` — SEO blueprint
- `content.html` — content calendar
- `ads.html` — advertising plan
- `whatsapp.html` — WhatsApp funnel
- `analytics.html` — measurement and KPIs
- `implementation.html` — setup roadmap
- `style.css` — shared styling

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files to the repository root.
3. Commit the files.
4. Go to **Settings → Pages**.
5. Choose the appropriate GitHub Pages deployment source.
6. Open the generated Pages URL.
